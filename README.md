# 如何安装

在使用汉化版本之前，请确定以下事项:
  - **确保汉化版与官方版版本号一致**: 如不一致覆盖后可能会导致一些兼容性问题
  - **确保官方版已安装并正常使用**: 如果你的官方版都无法运行就不要指望汉化版了。如何安装请见[官方仓库](https://github.com/scp222thj/MalumMenu)

如以上条件都已具备，请到当前仓库Release界面下载最新Release中的`MalumMenu.dll`文件，并覆盖`[游戏根目录]\BepInEx\plugins`的官方dll文件

再次运行游戏，即可成功安装汉化版
